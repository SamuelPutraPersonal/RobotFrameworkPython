Robot Framework & Selenium Automation Lab
This project is a scalable automation framework built for high-performance web testing. It is designed to be environment-agnostic, meaning it works exactly the same on a developer's laptop as it does in a cloud-based CI/CD pipeline.

🚀 Future Roadmap
This is a living project. While it currently focuses on Web UI testing, the architecture is being developed to support:

API Testing Integration: Using RequestsLibrary.

Database Validation: Checking backend data integrity.

Mobile Testing: Future support for Appium.

Parallel Execution: Implementing Pabot to run multiple tests simultaneously for faster feedback.

🛠️ The Toolbelt
The project is powered by a modern automation stack:

Core: Robot Framework (Keyword-driven).

Browser Engine: SeleniumLibrary with Chromium.

Environment Control: Docker for consistent test runners.

Development Experience: VS Code Dev Containers to eliminate "it works on my machine" issues.

CI/CD: GitHub Actions for automated regression on every push.
